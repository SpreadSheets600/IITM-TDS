# Question 6: Create a GitHub Action

## Solution

The task requires you to run a GitHub Action where at least one step has your exam email address as its name.

1. Create a new GitHub repository (or use an existing one).
2. Inside that repository, create a directory structure `.github/workflows/`.
3. Create a file named `main.yml` in that directory and paste the contents from `main.yml` located in this folder.
4. Commit and push your changes to GitHub.
5. Go to your repository's **Actions** tab on GitHub.
6. Click **"Run workflow"** under "My Email Logger Action" to manually trigger it.
7. Once the run successfully completes, copy the full URL of your repository and submit it in the exam portal!
